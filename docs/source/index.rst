Tenstorrent P150a Bringup
=========================

Setup and development reference for a **Tenstorrent Blackhole p150a** PCIe
accelerator on an Arch Linux workstation. Covers the installed stack — kernel
driver, hugepages, userspace tools, firmware, and the Metalium container
runtime — and the commands to reproduce it.
